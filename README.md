# GithubUser
Permet à A.V.A.T.A.R. de suivre les plugins des contributeurs , consulter leurs plugins A.V.A.T.A.R. et notifier automatiquement les mises à jour disponibles.

- This plugin is an add-on for the [A.V.A.T.A.R](https://avatar-home-automation.github.io/docs) framework. 

 ## 🎯 Usage
Commandes :
- quel sont les derniers plugins de stéphane, ou david, ou eddy ou halim

- Consultation des plugins A.V.A.T.A.R. d'un contributeur GitHub.
Détection automatique des nouveaux commits/mises à jour de plugins.
Notification vocale des mises à jour disponibles(scan tout les 2 heures).
Gestion multi-contributeurs GitHub via la configuration.
Support multilingue avec les fichiers .pak.

## Multi-room

The GithubUser plugin is fully multi-room.

## Multi-language

The GithubUser plugin relies solely on the system's available languages.
